# DOOM 怪物状态机拆解案

**DOOM（1993）· 第一人称射击 / 敌人设计**

DOOM（1993）的怪物状态机，怎样同时做到「压得住」和「打不过」？

这是本站第一篇专门拆敌人的文章。它读 id Software 公开源码的状态表与怪物参数表，把「抬手多长、能不能打断、跑不跑得掉」全部换算成 tick 与概率，再用一台逐 tick 的时间线把整场正面交火重跑一遍。

## 先了解这篇文章

**爽感与难度在这套结构里是同一张表的两端。** 18 种算作击杀的怪物共用同一套通用动作（`A_Look`、`A_Chase`、`A_FaceTarget`、`A_Pain`、`A_Scream`、`A_Fall`），每类再加一到两个攻击动作，差异全部塞进数据表：状态时长、生命、速度、质量，以及一个叫 `painchance` 的数。

**「压得住」长在三样确定的东西上**：可读的抬手（常见杂兵 0.29～0.46 秒，同种怪物完全一致）、可打断的硬直（霰弹枪对杂兵每发必断，而且打断会真的取消攻击）、跑得掉（玩家约 16.67 单位/tick，最快的怪只有 7.5）。**「打不过」则全部来自数值、数量与空间**：状态机里没有闪避、掩体、预判和协同，想更难只能改数字、加怪、改地图。九张第一集地图里，七成扇区比一只恶魔的身位还窄；困难难度比简单多出约 3.9 倍的怪。

`painchance` 从 200 铺到 10，把「杂兵 / 精英 / BOSS」三档分得干干净净。把整场交火逐 tick 跑一遍能看到效果：小恶魔在三档武器下都是 94～100% 的零出手击杀，一次都没打出来；赛博恶魔则要在 15～61 秒的战斗里还手 11～51 次。

## 沿着三个问题阅读

### 「压得住」和「打不过」为什么是同一个数？

每次造成伤害，游戏掷一次 `P_Random() < painchance`；命中就把怪物当前状态换成疼痛状态，抬手到一半的攻击被取消。这个数在杂兵身上是 200（霰弹枪一次开火必断），在赛博恶魔身上是 20（一次开火只有 36%）。把赛博恶魔的这个数改成 0 / 40 / 80，就能看出「爽」和「难」是同一个旋钮的两端。

**阅读路径：**[一个数决定压不压得住](./full.md#section-3-1) → [压制靠弹丸数，不靠伤害](./full.md#section-3-2) → [把 20 改成 0 / 40 / 80](./full.md#section-3-3) → [断点把三档分干净](./full.md#section-3-4)

### 玩家的「爽」到底长在哪几个机制上？

三样：抬手固定且可读、硬直真的取消攻击、即便不打断也有三道出手闸门（反应时间 8 次追击、步数计数器归零、打完必须走一步）。把这三样放进一条逐 tick 的时间线，才能回答「我能不能在它出手之前把它打死」。

**阅读路径：**[可读的抬手](./full.md#section-5-1) → [可打断的硬直](./full.md#section-5-2) → [三道喘息闸门](./full.md#section-5-3) → [把整场交火跑一遍](./full.md#section-5-5)

### 难度为什么只能靠数值和地图？

因为怪物 AI 只有四件事：找目标、直线接近、按距离选近战或远程、撞墙换方向——没有闪避、掩体、预判、协同。于是难度只能来自数值、数量与空间：生命 20 → 4000、火箭快过玩家、两个 BOSS 免疫全部爆炸溅射；九张图七成扇区比一只恶魔还窄；同一个难度旋钮同时改数值和数量。Nightmare 难度只改三处，全是数值和开关，**没有一处新增行为**。

**阅读路径：**[只有四件事](./full.md#section-4-1) → [九张图有多窄](./full.md#section-4-4) → [数量与群体](./full.md#section-4-5) → [难度旋钮只有三个](./full.md#section-4-7)
