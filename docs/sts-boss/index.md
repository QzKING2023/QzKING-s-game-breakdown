# 反无限 BOSS 拆解案

**杀戮尖塔 / 敌人设计（对比型）**

反无限 BOSS 怎样限制循环，又让玩家有办法应对？

时间吞噬者、门扉缔造者和永世沙漏都干涉连续出牌，但它们交给玩家的问题差别很大：一个把出牌次数变成公开预算，一个轮流限制核心牌复用、额外抽牌和能量，一个让连续出牌产生凋萎、再要求玩家处理伤害与污染。

## 先了解这篇文章

**判据是四项，不是胜率排名。** 限制覆盖了什么行为、代价能否提前看清、玩家能否继续使用原有工具、针对性准备是否换来可预期的回报。文章由此给出的评价是：时间吞噬者的设计最成熟；门扉缔造者是一次没有达到官方复杂度目标的尝试，普通运转受牵连、零费循环又能绕过紧握；永世沙漏保留了更多用原有引擎应对的空间，却仍可能让慢速、高频构筑承担过重的污染成本。

**三条规则的落点不一样。** 老头把出牌次数变成跨回合的十二张计数；沙漏每累计六张牌向手里加一张凋萎，计数跨回合、凋萎可挡可弃；门扉在三个阶段轮流限制核心牌复用、额外抽牌与能量。

**「无限」有严格定义。** 它指启动后能持续回收组件、补足所需资源的出牌闭环；牌组较小或单回合出牌很多，都不自动满足这个条件。这条定义决定了后面能下多强的判断。

## 沿着三个问题阅读

### 三个 BOSS 各自限制了什么？

老头硬性截断当回合出牌，但把机会做成跨回合、可计算的十二张预算，循环仍可拆成多个有限回合；沙漏保留抽牌、回能、弃牌与格挡，代价是计数继续累积；门扉在不同阶段限制不同的东西，因此压制不均衡，还可能牵制玩家的补救手段。

**阅读路径：**[出牌次数成为预算](./full.md#section-2-1) → [沙漏的计数与凋萎](./full.md#section-2-2) → [门扉的三阶段](./full.md#section-2-3) → [老头：硬规则下仍能改进原有引擎](./full.md#section-6-1)

### 改一个参数，会改变什么？

把老头的阈值从十二张挪到相邻值，改变的是有限收益：模型里 11 / 12 / 13 张对应的亮剑与妙计次数、伤害与格挡都不同，但接住随后三段攻击的损血只差两点。把沙漏的生成间隔从六张试调到七张，则同时减少污染、放宽高频收益——这是本篇唯一验证过的改动。

**阅读路径：**[相邻阈值改变的是有限收益](./full.md#section-3-1) → [凋萎的生长与清理](./full.md#section-3-2) → [先试调沙漏的污染间隔](./full.md#section-7)

### 门扉被删，能证明什么？

能证明官方放弃了这一版的复杂度（官方同时承认其中有有趣的微观决策），**不能证明每一条批评都已证实**。文章把「普通付费运转承担明显成本」与「某些零费无限可能利用阶段规则绕过紧握」分开陈述，并标明后者依赖一条尚未独立复验的旧版录像观察。

**阅读路径：**[门扉在三阶段限制什么](./full.md#section-2-3) → [零费闭环的条件推导](./full.md#section-4-3) → [同一高度下怎么比](./full.md#section-6-4) → [仍待验证的问题](./full.md#section-8)
