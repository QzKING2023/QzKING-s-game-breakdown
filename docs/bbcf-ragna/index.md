# BBCF 角色拆解案：拉格纳

**苍翼默示录 神观之梦 · 2D 格斗 / 帧级拆解**

拉格纳以优秀的中近距离技能取得接触，靠贴身压制争取命中，再用连段取得伤害、吸血与击倒。他的招式能在较远处碰到对手，但整套打法的收益仍集中在接近之后。文章的定位是：他是「接触型强角」——偏长的普通技和中等机动性让接触不算困难，吸血把接触变成续航，均火在上游；代价是破防手段相对普通，摸不到人就是白板，低血量放大失误。

文章沿着一次进攻的过程，拆开牵制技的距离与持续、命中确认、取消路线和压制出口，同时检查对手的应对和拉格纳承担的风险。

## 这篇文章关注什么

吸血让一次命中同时改变双方的血量差，也让拉格纳有理由继续争取进攻。不过，实际恢复量受招式、连段中的吸血次数和自身缺失血量约束；普通防御与屏障防御的结果也不同。低基础血量和吸血要放在一起看，才能解释他的生存能力。

一招被防后是负帧，仍可能是好牵制。风险还取决于距离、取消，以及对手够不够得着。文章用具体的时间轴和对手选项，区分“主动停手”“留缝继续压制”与“已被确反”。

横向对比也围绕这些局面展开：谁更容易取得接触，谁能继续压制，谁有更好的远距离手段或脱身办法。连段样本用来判断常规路线够不够用；角色定位另见 §6 的判断。

## 可迁移的设计原则

- **负帧不能脱离取消树与接触距离孤立估值（反模式：单看收招帧差定招式安全度）**：当技能拥有多帧持续、逐步前伸判定或丰富取消路线时，被防负帧只描述“不取消且近端被防”的单一结局；实际风险由接触距离、取消连防／留缝分支与对手反制窗口共同决定（本案依据：`5B` 不取消为 −7～0F，但最快取消覆盖连防与 4–8F 缝，远端判定至第 10 帧才伸展到 399 px，见 [§2.1](./full.md#section-2-1)、[§3.1–3.2](./full.md#section-3-1)）。
- **防御系统改动必须回查攻方短缝阈值（原则：按常态与精准防御两套硬直重算压制表）**：只要引入缩短防御硬直的通用防守机制，原有压制链里的连防与 1–2 帧短缝就会整体松动甚至反转先后手，设计压制分支须在两套硬直口径下同步验证（本案依据：IB 使地面防硬减 3 帧，`5B > 214A` 由 −1F 连防拆出 +2F 缝，`5B > 6D` 对 5F 抢招由 0F 同帧反转为守方早 3F，见 [§3.4](./full.md#section-3-4)）。
- **进攻续航与基础容错应纳入同一预算（原则：独立回复链配高失误成本）**：给近身压制型角色配置命中／削血回复时，需将回复与连段补正拆成独立结算链以保证功能可读，同时用较低基础血量与无远程牵制放大空挥和进身失误的代价（本案依据：噬魂剑独立于连段补正结算，单套短连即可改变 2233 血差，由低基础血量与中远距离白板期构成代价，见 [§2.3–2.4](./full.md#section-2-3)、[§4.1](./full.md#section-4-1)）。
