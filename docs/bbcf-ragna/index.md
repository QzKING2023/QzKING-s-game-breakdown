# BBCF 角色拆解案：拉格纳

**苍翼默示录 神观之梦 · 2D 格斗 / 帧级拆解**

拉格纳以优秀的中近距离技能取得接触，靠贴身压制争取命中，再用连段取得伤害、吸血与击倒。他的招式能在较远处碰到对手，但整套打法的收益仍集中在接近之后。文章的定位是：他是「接触型强角」——偏长的普通技和中等机动性让接触不算困难，吸血把接触变成续航，均火在上游；代价是破防手段相对普通，摸不到人就是白板，低血量放大失误。

文章沿着一次进攻的过程，拆开牵制技的距离与持续、命中确认、取消路线和压制出口，同时检查对手的应对和拉格纳承担的风险。

## 这篇文章关注什么

吸血让一次命中同时改变双方的血量差，也让拉格纳有理由继续争取进攻。不过，实际恢复量受招式、连段中的吸血次数和自身缺失血量约束；普通防御与屏障防御的结果也不同。低基础血量和吸血要放在一起看，才能解释他的生存能力。

一招被防后是负帧，仍可能是好牵制。风险还取决于距离、取消，以及对手够不够得着。文章用具体的时间轴和对手选项，区分“主动停手”“留缝继续压制”与“已被确反”。

横向对比也围绕这些局面展开：谁更容易取得接触，谁能继续压制，谁有更好的远距离手段或脱身办法。连段样本用来判断常规路线够不够用；角色定位另见 §6 的判断。
