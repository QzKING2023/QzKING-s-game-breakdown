# BBCF 角色拆解案：拉格纳

**BlazBlue: Central Fiction · 2D 格斗 / 帧级拆解**

Arc 把拉格纳设计成「相对简单、却没有顶尖强度」。这份简单与这个上限，分别由哪些帧数与数值选择兑现？

这一页拆到招式级：逐招的发生 / 持续 / 收招、命中与被防有利帧、补正与判定框，再把同一个招式位放进全 36 名角色里并排，最后回到设计者视角，看 Arc 在他身上做了什么取舍、代价是什么。帧数据来自游戏脚本与碰撞文件（读取日期 2026-10-22），并与 Dustloop 的帧数页逐字段核对。

## 先了解这篇文章

文章先给**判据**再给结论：顶尖角色至少有一组能独立成立的长板，而「没有短板」不等于「有长板」。把拉格纳和社区公认的顶尖三人放进同一组指标（走速、`66` / `44`、对象状态数、判定由生成物承载的招式数、回报、血量）之后可以看到，那三人各有一块「角色之外的一半」——雷琪儿的设置物、卡璐璐的傀儡、哈扎马的链条，而拉格纳没有任何一组能独立成立。所以「不顶尖」指的是**长板不够长**，不是「哪一项差」。

「好上手」的答案在取消表里：`5B > 5C > 2C > 2D > 236D~66` 这样的压制链每一环都能「打中就转连段、被防就停下或继续」，地面通常技一个目押窗口都没有，常见连段组件对所有角色通用；连段的进阶部分对他也几乎不加伤害（独立样本里只 +5.5%）。他的上限则由四项锁住：全招被防为负、中段不安全、没有远距离手段、容错与斩杀线都偏下——他的均火在上段（32 支视频样本里基础连段第 3 / 19），但**斩杀平庸**（上限第 30 / 32），OD 对他是「回血」而不是「斩杀」。

## 沿着三个问题阅读

### 他的「好确认」，在帧数上是什么？

不是 `5B` 的 8 帧持续——那是覆盖，用来拦人和压起身。好确认来自取消表：`5B` 之后有 8 个通常技加必杀技可选，命中有利帧又只有 −6 到 +1，所以确认永远是取消、不是目押，链上的每一环都能停下来看清命中还是被防。

**阅读路径：**[`5B` 的时间轴](./full.md#section-2-1) → [打中之后能接什么](./full.md#section-2-4) → [取消树与零目押](./full.md#section-2-5)

### 他看起来强，为什么打不出「顶尖」？

单看发生、持续、判定三项，他的 `5B` 是全游戏最强的中距离通常技之一；代价是被防 −7，中段在链里留 8~13 帧会被抢，`214A` 的长突进被防就是贴脸 −4。他的判定强项都在 400 像素上下，超过这个距离的手段都被赔率压了回去。回报也是同一种形状：均火在上段（32 支视频样本里基础连段第 3 / 19），斩杀线却在下段（非 OD 上限第 30 / 32），从常规切到 Overdrive 的收益还是 32 人最低。

**阅读路径：**[`5B` 位横向对比](./full.md#section-3-8) → [压制链与对手的回应](./full.md#section-3-3) → [中段](./full.md#section-3-5) → [没有远距离手段](./full.md#section-3-6) → [回报的交叉验证](./full.md#section-4-4)

### 「Shoto 变体」这个说法成立吗？

文章把它拆成可检验的部件：升龙与突进技成立，飞行道具只有形态没有功能——`236D` 是 26 帧派生发生、约 144~240 像素射程的投射物，短于他自己的 `5B`。

**阅读路径：**[投射物与 2D 位](./full.md#section-3-6) → [抗压](./full.md#section-4-2) → [对空](./full.md#section-4-3) → [四条优势 / 四条代价的检验](./full.md#section-6-6)

### 他是哪一种角色的标准？

Dustloop 把拉格纳写成「a very beginner friendly rushdown character」。把同为 rushdown 定位的四人（直人 / 照美 / 梵克汉 / 诺爱儿）放进同一组指标之后，结论分三层：他的取舍是同类里的**基准**、方向**偏保守**（四人各有一组能独立改变局面的复合长板，他没有）；长板判据成立，而且在同类里才看得出「**能复合的长板才算长板**」；「最标准的那个」只能证到「状态机最干净 + 核心位居中偏上 + 五人里唯一被社区写成『标准』」，**排名本身证不到**，标推断。

**阅读路径：**[同类定位（五人并排）](./full.md#section-6-6) → [回报的两份样本](./full.md#section-4-4) → [抗压](./full.md#section-4-2)
