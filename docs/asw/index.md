# 从角色看系列的变迁与格斗游戏的发展

**Guilty Gear / BlazBlue · 2D 格斗 / 系列演变**

格斗游戏这些年变简单了吗？如果变简单了，系统的深度又放到了哪里？

这篇拆解以 Arc System Works（ASW）的两个招牌系列为对象，选了四个贯穿历代的角色：基准角色 Sol 与 Ragna，高难角色 Zato 与 Rachel。比较他们在各代的核心连段、取消规则和专属机制，看“更简单”和“保深度”怎样同时成立。

[阅读全文 →](./full.md) · <DownloadSource href="/downloads/asw-character-evolution.md" filename="ASW角色变迁拆解案.md" />

## 先了解这篇文章

核心判断是：**格斗游戏并没有走向“快餐化”。ASW 面对的问题是怎样在变得更简单的同时，保住系统的深度。** 基准角色的核心连段确实变容易了，高难角色的核心机制却一直保留；连段的角色限定只在 Guilty Gear 一线被系统性地削减，BlazBlue 正作始终是一款高难度的游戏。

文章把难度分成两层：执行层（手上功夫）和决策层（资源与判断）。帧数表只能回答“有没有窗口”，所以每套连段都被拆成取消、目押、空中追打、延迟与位置依赖四类衔接，再补上帧顿、输入缓冲和取消窗口这些帧数表里看不到的因素。

## 沿着三个问题阅读

### 主角的核心连段，到底简单了多少？

这里不看入门连段，只看角色实际对战时常用的 Core BnB。Sol 的核心连段在 Strive 明显变短，手动延迟和角色限定都没有了；Ragna 的正作连段没有变短，变化在于最紧的窗口放宽了，以及 BBTag 的整体简化。

**阅读路径：**[怎么衡量难度](./full.md#section-1-4) → [执行层：Core BnB](./full.md#section-6-1) → [汇总表](./full.md#section-6-5)

### Strive 的手感变宽松，来自帧顿还是规则？

文中的帧顿数据、攻击等级和取消窗口的终点，是从 Xrd REV 2、Strive、BBCF 的游戏脚本与碰撞文件里读出来的。GG 系列从 XX 开始的三代的帧顿没有变。Strive 的放宽来自更长的输入缓冲，以及把 Xrd 逐招设定的收招取消统一成通用规则；轻攻击的确认窗口并没有变宽。

**阅读路径：**[Strive 的设计](./full.md#section-4-2) → [帧顿、输入缓冲与取消窗口](./full.md#section-6-2) → [两个系列的不同取舍](./full.md#section-7-2)

### 变简单之后，高难角色的深度还在吗？

Zato 的槽和 Rachel 的风是两人的核心资源。文章逐代比较它们的规则，并统计 Dustloop 连段页里“只对特定角色成立”的条目比例。角色限定在 GG 一线明显收窄，在 BB 一线没有明显变化；高难角色的核心机制一直都在。

**阅读路径：**[角色限定](./full.md#section-6-3) → [决策层：资源与判断](./full.md#section-6-4) → [平衡点要持续调整](./full.md#section-7-3)
