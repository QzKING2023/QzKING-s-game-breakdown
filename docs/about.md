# 关于我

我是 **QzKING2023**，以战斗策划为方向，关注角色招式、敌人行为与资源系统的设计。

我习惯把游玩中遇到的问题记下来，再顺着规则、数值和玩家的实际选择，弄清这些体验是怎么来的。这里展示我的分析、设计判断、改造方案与个人原型；游戏本身的设计、官方资料与社区研究会在文章中注明来源。

## 设计实验

[FTG 角色原型：D 系位移与连段选路](./ftg-demo/)把“简化位移攻击输入，保留连段选路”的问题做成 Godot 原型。角色以 D 系组织位移攻击，形成双换边搬运、抵墙短线与版边保位；案例展示招式职责、路线取舍和机器验证。八个样本的路线功能已交付，操作宽容度与真人体验待验收。

- [从角色看系列的变迁与格斗游戏的发展](./asw/)：ASW 两个格斗系列怎样降低门槛、保留深度
- [战地风云 6 Gunplay 拆解](./bf6/)：随机后坐力与扩散怎样影响枪法
- [Valheim 战斗系统拆解](./valheim/)：难度倍率、资源成本和召唤法杖怎样架空近战
