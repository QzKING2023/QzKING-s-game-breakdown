# 关于我

我是 **QzKING2023**。这里放的是我对游戏的拆解与观察。

我习惯把游玩中遇到的问题记下来，再顺着规则、数值和玩家的实际选择，弄清这些体验是怎么来的。有的文章拆一款游戏的某个系统，有的沿着时间看一种规则怎样演变。目前的文章（按发布时间由新到旧）：

- [《杀戮尖塔》两代设计方向](./sts/)：系列总纲——二代的限制分别作用于构筑取得与战斗使用，普通运转也承担连带成本
- [静默猎手两代拆解](./sts-silent/)：从取得、启动、兑现到抗干扰，逐层对照两代规则，看官方目标兑现了多少

- [射击的进化史](./shooting/)：一次交火的结果怎样在玩家与系统之间划分，从街机讲到战地风云 6

- [Valheim 战斗系统拆解](./valheim/)：难度倍率、资源成本和召唤法杖怎样架空近战
