# Valheim 战斗系统拆解

**英灵神殿 · 生存建造 / 动作战斗**

一套成熟的动作战斗循环，为什么会被难度倍率、资源成本和召唤法杖联手架空？

格挡、招架、闪避和双向架势，本来构成了一套清晰的战斗循环。可随着难度、敌群和成长成本一层层叠加，不同流派的玩家要承担的风险差得越来越远。这篇拆解就从这里展开。

## 先了解这篇文章

我分析了游戏代码和预制体数值，读取了动画时间，又做了遭遇战模拟，想把游玩时的体感还原成可以讨论的机制。核心观察是：**不同打法之间的风险收益差异，很大程度上取决于“由谁承受敌人的攻击”。**

下面是阅读导引。模拟结果依赖文中设定的场景和模型假设，具体数据、适用条件和方法说明都在全文里。

## 可迁移的设计原则

- **警惕非线性减伤公式与难度倍率的二次方放大（反模式：在平方区直接叠乘全局敌人伤害倍率）**：当护甲与格挡共用非线性减伤公式且落入平方区时，线性抬高敌人伤害会令实际穿透伤害与架势压力按平方放大，瞬间制造出未预期的难度断崖（本案依据：困难预设 1.5 倍伤害在平方区放大为 2.25 倍，沿结算链同时放大承伤、格挡残余与架势爆条，见 [§2](./full.md#section-2)、[§4.3](./full.md#section-4-3)）。
- **高难数值验收必须校验“由谁承担攻击”的流派风险差（反模式：只按近战直伤调高难度，忽略仇恨与距离转移）**：当难度倍率只重压直接承伤的近战防御循环，而远程靠射程地形、召唤靠单位吸仇恨即可绕开大部分防御结算时，高难环境会系统性架空原本成熟的近战动作循环（本案依据：平原起高难近战出现明显死亡断崖，召唤法杖与非魔法远程却大幅转移或规避了防御压力，见 [§5.8](./full.md#section-5-8)、[§10](./full.md#section-10)、[§11](./full.md#section-11)）。
- **跨区域进入期不能只凭“挨一刀表格”验收（原则：以上一区域毕业装叠加巡逻与刷新密度做遭遇模拟）**：单次攻击公式在纸面上常表现为可格挡、可招架，但放进真实进入期装备、多怪巡逻与高频刷新环境后，连续架势与体力消耗会迅速滚雪球崩溃（本案依据：单击承伤表看不出断崖，直到以上一区域满级装备进入遭遇战模拟才暴露北境平原断崖，见 [§5.5](./full.md#section-5-5)、[§5.6](./full.md#section-5-6)、[§5.8](./full.md#section-5-8)）。

## 沿着三个问题阅读

### 伤害倍率为什么会放大防御压力？

护甲和格挡共用同一个伤害公式，在平方区，这个公式会把伤害倍率再放大一层。据此可以看到困难难度怎样同时改变承伤、格挡后的残余伤害和架势压力，文中也比较了魔法屏障在结算顺序中的位置。

**阅读路径：**[伤害结算管线](./full.md#section-2) → [难度倍率](./full.md#section-4-3) → [架势条](./full.md#section-8)

### 跨区域的难度，为什么不能只看敌人的一刀？

以刚进入新区域时的装备为基准，把巡逻队、杀人蜂、刷新频率和资源获取放进同一个场景里考察。对平原的判断分普通和困难两种难度，也区分了可以绕开的强敌和躲不掉的高频遭遇。

**阅读路径：**[模拟模型与依据](./full.md#section-5-6) → [平原断崖](./full.md#section-5-8) → [护甲的资源成本](./full.md#section-6)

### 流派的差异，如何改变玩家参与战斗的方式？

近战由玩家直接承受防御压力，远程依靠距离和地形，召唤系则把敌人的攻击转给召唤物。文章从仇恨、寻路、持续输出和资源成本几方面，讨论每种选择要什么条件、换来什么收益。

**阅读路径：**[魔法与近战](./full.md#section-10) → [非魔法远程](./full.md#section-11) → [设计改进方向](./full.md#section-14)
