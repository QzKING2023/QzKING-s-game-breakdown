# Valheim 近战防御管线改造

**英灵神殿 · 生存建造 / 系统改造**

近战防御管线在困难难度下会把玩家推向「全有全无」的断崖。如果只改这条公式、保留其他所有设计，能拆掉断崖吗？代价是什么？

这一篇是[《Valheim 战斗系统拆解案》](../valheim/)的续篇。主文拆过护甲、格挡、架势这条管线，也量过它的代价，并在最后一章列了 20 条改法——**一条都没验证过**。这一篇只做一件事：**把这条管线改一遍，然后用同一台遭遇战模拟器跑出改动前后**。

## 先了解这篇文章

**防御公式能买到的是一条又窄又准的改动。** 把「护甲计入架势阈值」和「格挡残余只累积一遍」两条公式，加上「格挡 / 招架分账」和「硬直结束时架势清零」两条系数组合起来，困难难度的平均死亡率从 **59.1% 压到 44.9%**（−14.2 个百分点）、「100% 死亡格」从 **42 格削到 30 格**，而普通难度只从 8.3% 降到 7.8%。

**但断崖没有被消灭。** 剩下的 30 格里，玩家死时敌人还剩 31%~97% 的生命——它们差的是**敌人血量池与硬直时长**，不是防御公式。防御面能改的只有「玩家会不会被一次爆条连锁打死」这一件事。

文章先说清这条管线怎么运转、断崖长什么样，再逐条量出每个改法的方向与代价，最后给出采纳的方案、以及「把路全开能到哪」的上限。

## 沿着三个问题阅读

### 断崖到底是「血量」问题，还是「架势」问题？

把两个纯旋钮分别拉到底就能回答：把架势累积压到 3 成，困难平均死亡 58.3 → 47.5，而普通只从 8.7 掉到 8.2——**靶向性 21.6 : 1**；把有效生命抬到 1.82 倍虽然也能到 46.7，但普通会从 8.7 塌到 4.6——**靶向性只有 2.8 : 1**。架势轴在均值上贵 4~8 倍划算。

**阅读路径：**[等量曲线](./full.md#section-3-1) → [机制分解](./full.md#section-3-3) → [决定性发现](./full.md#section-3-4)

### 如果只改一条公式，该改哪一条？

「护甲计入架势阈值」单独把困难平均死亡压 58.3 → 50.2、100% 格 39 → 31，靶向性 18:1，普通只降 0.4 pt——它是唯一同时拿下「均值」和「计数」的一条，作用面与「举盾的人」完全对得上。而主文点名的「残余伤害计两次架势」确实是结构缺陷，但只值 −1.3 pt。

**阅读路径：**[单旋钮消融](./full.md#section-5-1) → [① 的系数](./full.md#section-5-2) → [代码核对](./full.md#section-6-4)

### 为什么断崖消灭不了？

因为「100% 死亡格」这个计数主要不是防御问题。困难基线 39 格里，玩家死时敌人还剩 31%~97% 生命；把有效生命抬到 5 倍、架势压到 3 成，仍剩 10 格。防御面这一侧到顶之后，剩下的是**武器伤害类型**与**遭遇档次**——那不在防御公式里。

**阅读路径：**[决定性发现](./full.md#section-3-4) → [对 J1 的答复](./full.md#section-7-3) → [武器那一半](./full.md#section-8)
