# BBCF 角色拆解案：雷琪儿

**苍翼默示录 神观之梦 · 2D 格斗 / 帧级拆解**

雷琪儿可以先用飞行道具和设置物限制对手，再借风改变移动轨迹，接近对手并组织起攻。一次吹风有时能同时帮助本体与场上的物体；连续使用时，进攻、调整位置和脱身又会争用有限的风槽。

文章从部署开始，逐步分析设置怎样形成威胁、风怎样改变接触时机，以及击倒后的进攻与对手的反制。

## 同样拥有设置，打法为何不同

奈茵、莉琪和 μ-12 都有能留在场上或延后生效的攻击，但这些工具在各自打法里的作用不同。奈茵偏重中远距离牵制；莉琪的切换与设置支持多种距离的应对和强力择；μ-12 则把设置融入机动、牵制和高回报的全面打法。

雷琪儿的区别要从风的作用来看：她能协调本体与物体的运动，用已有的场面掩护接近，争取命中与击倒，接入后续起攻。文章把几人放进相同的局面比较，避免仅凭“都有设置”就归为同一种玩法。

风用完以后，这套能力会减弱，但招式并未全部失效。青蛙仍会自行移动，其他物体也有各自的运动与消失条件。把这些条件写清楚，才能判断她什么时候可以继续施压，什么时候需要等待、转移位置或重新准备。
