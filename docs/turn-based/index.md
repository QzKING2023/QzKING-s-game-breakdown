# 回合制的进化史

**从兵棋到 2026 年 · 回合制 / 设计史**

“回合制已经过时”和“回合制正在复兴”，在同几年里都有人说，也都有证据。2023 年，《最终幻想 XVI》的制作人说动作化“差不多是唯一的办法”，同年回合制的《博德之门 3》拿下了 The Game Awards 年度游戏。

这篇文章不拆单一作品，而是沿着时间，看回合制这条规则从哪里来、被用在了哪些游戏上，又是怎样一路变成今天这个样子的。

## 先了解这篇文章

回合制最初的承诺是：世界停下来，等你想清楚。它的代价也一直是那几样：节奏变慢，写实画面里角色站着等指令显得别扭，轮到对手时只能干看着，掷骰的结果又常常让人觉得被系统欺负。

文章的看法是，设计者对这些代价的回应大致分成两类。一类让时间重新流动起来；另一类保留“世界会等你”这个前提，把回合拆开交给玩家去操纵。拆开之后主要有三个杠杆：**顺序**（谁先动）、**次数**（一回合动几次、能不能交给别人）、**概率**（结算能不能改、看不看得见）。每放开一个杠杆，设计者通常也会配一套机制把它收回来一点。

## 沿着三个问题阅读

### 回合制是被硬件逼出来的吗？

没有哪位早期设计者这样说过。从普鲁士兵棋的两分钟一回合、Gygax 解释的“大体可控”，到《巫术》把裁判换成程序，回合的粒度从一开始就是一种设计选择。硬件让回合制成了顺理成章的选择。

**阅读路径：**[把同时发生的事切成片](./full.md#section-1) → [电脑接过裁判](./full.md#section-2) → [让时间流起来](./full.md#section-4)

### 同一个杠杆，三个系列怎样放开又收回？

女神异闻录一线在重罚和纯奖励之间来回调整次数；轨迹从方格战场和 AT 条出发，一直把顺序当作核心；幽浮从 1994 年藏在 TU 背后的反应队列，走到 2012 年公开的命中率和背后的隐藏补偿。三处插框用到了本机游戏文件的取证。

**阅读路径：**[女神转生 / 女神异闻录](./full.md#section-8) → [轨迹](./full.md#section-9) → [幽浮](./full.md#section-10) → [三条线并排](./full.md#section-11)

### 把规则推到极端，会发生什么？

《陷阵之志》取消了命中率，失败条件只好转移到不会跑的建筑上；《节奏地牢》给回合加了一个时钟；《33 号远征队》把执行层放进了敌人的回合，再把格挡的成果折算成下一回合的 AP。

**阅读路径：**[取消概率](./full.md#section-12) → [把时钟塞回回合里](./full.md#section-14) → [星之海与 33 号远征队](./full.md#section-17)
