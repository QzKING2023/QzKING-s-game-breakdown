# Valheim BOSS 拆解案

**英灵神殿 · 生存建造 / BOSS 设计**

Valheim 的 BOSS 没有专属 AI，难度只靠四组数据字段拧出来。那么它们各自在考玩家什么？把其中一场改一遍，又要付出什么代价？

这一篇补上主文留下的缺口：把七个主线 BOSS 加上 1.0 新增的深北 BOSS 一起拆完——招式表、阶段、弱点、逃课与手感都从代码、预制体与动画资源读出（读取日期 2026-10-21）。最后一章把第六关的蛊虫之后改成三幕，并用同一台遭遇战模拟器跑出改动前后。

## 先了解这篇文章

八个 BOSS 在代码里没有专属 AI，全部挂在和野外狼群、丑地精完全相同的 `MonsterAI` 上。BOSS 与普通敌人的全部差别只来自四组数据字段：**血条长度、牌堆、牌堆什么时候变、哪些牌必须走位处理**。由此得到两个可验证的推论：BOSS 战真正的门槛是“带对武器”和“记住每张牌的预兆”；而主文证明过的三条逃课（站到够不着的地方、召唤物吸仇恨、远程放风筝）在 BOSS 战里同样成立。

评价一章给出七条成功与九条失败，其中最要紧的一条是：玩家在第一关（赤血灵鹿）学会的“招架 → 踉跄 → 双倍伤害”，从第二关起就只剩减伤——因为只有它保留了招架踉跄。

最后一章把失败点落成一次**经过验证的改造**：给第六关的蛊虫之后设计三幕，只改预制体字段，不动引擎代码。改动的收益和代价都被量化——招架那一格从“打不完”变成“打得完”（一场造成伤害 +108%），但把四个近身技的推力从 250 降到 100，反而让“站桩硬吃”的格挡格死亡率从 34.0% 升到 66.7%：**位移在这个游戏里不只是惩罚玩家，它同时是玩家的保护。**

## 沿着三个问题阅读

### 八个 BOSS 的难度，到底由什么决定？

它们共用一套野外 AI：每 2 秒选一次目标、每 1 秒在冷却完毕的牌里等概率抽一张，没有距离加权、没有连段、也没有“血量低就放大招”。真正的差别只来自四组字段——血量、牌堆、血量门（`m_aiMin/MaxHealthPercentage`）与哪些牌不可挡/不可闪。于是每一关的“正确答案”其实是**带对武器**（抗性表）与**记住每张牌的预兆**。

**阅读路径：**[BOSS 用的就是野外 AI](./full.md#section-4-1) → [招式表怎么读](./full.md#section-4-2) → [赤血灵鹿：唯一教会你招架的一关](./full.md#section-4-3) → [蛊虫之后：唯一一条反向解锁曲线](./full.md#section-4-5)

### 为什么“招架”在第二关就不灵了？

玩家在赤血灵鹿那里学会的核心循环是“招架 → 踉跄 → 双倍伤害”，但八个 BOSS 里只有它保留了招架踉跄（`staggerWhenBlocked = 1`），其余七个的招架都退化成“少挨一点”。同时八个 BOSS 的 `staggerDamageFactor` 全是 0，所以它们也不可能被伤害打出踉跄——这条规则专门削弱的是“读招完美”的玩家。

**阅读路径：**[三条断点](./full.md#section-3-1) → [把“不可踉跄”拿掉](./full.md#section-3-3) → [失败的部分](./full.md#section-6)

### 把一场 BOSS 战改一遍，会付出什么代价？

改造只改预制体字段，把蛊虫之后切成三幕、打开招架踉跄、接上头部弱点、收窄位移。结果是招架格从“打不完”变成“打得完”，但位移降低对“站桩硬吃”的打法是净亏损——因为位移在模型里是对称的：玩家被推走时 BOSS 也得走回来。这次改造**没有解决**的问题（实机手感、地形、召唤物仇恨）也逐条写明。

**阅读路径：**[三幕与切换判据](./full.md#section-7-1) → [招式表与窗口](./full.md#section-7-1) → [模拟验证与代价](./full.md#section-7-1)
