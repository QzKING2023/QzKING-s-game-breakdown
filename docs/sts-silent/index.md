# 静默猎手两代拆解

**杀戮尖塔 / 角色拆解（两代对照）**

二代怎样改变静默猎手的构筑选择，官方目标兑现了吗？

静默猎手在两代里都靠抽牌、弃牌和保留安排关键回合。二代改变得更明显的，是把这套运转搭起来、再安全兑现的条件。文章围绕四件事取证：**能否取得组件、取得后怎样启动、启动后怎样兑现、受到敌人干扰后还能做什么**——卡牌的印刷数值只回答其中一部分。

## 先了解这篇文章

**运转是多种猎手策略的共同基础，不能只归给弃牌流。** 杂技同时抽牌、净增手牌、提供弃牌口；收场要推进牌堆，子弹时间要聚拢手牌，小刀与毒防都要及时找到配套。杂技白卡升蓝卡改的是组装过程，连带影响奇巧以外的多条路线。

**组合能成立，不代表值得提前抓齐零件。** 本能、战术要与弃牌口配对（已知战术在手、另有 1 / 3 / 5 张弃牌口时，同手出现弃牌口的条件概率是 16.7% / 43.7% / 63.5%）；能量要扣除副作用、配对与时机成本；二代 A6 起商店五次删牌从 625 金涨到 1000 金，会与抽弃供给收紧相叠加。

**在这些条件下，低费持续毒与功能冗余的防御更有吸引力。** 毒雾部署后持续施毒，灵动让原有防牌继续成长，收益接口较宽。代价同样具体：只靠一张中和+，理想循环下名义虚弱覆盖仅约三分之一；单张基础毒雾到第五个敌方回合累计也只有 14 伤。文章把毒防称为**有机制依据的适应路线**，而不是全体玩家的流派占比或胜率排名。

## 沿着三个问题阅读

### 二代到底改了「牌」，还是改了「拿到牌的过程」？

杂技升蓝之后，同一张牌抽弃的手牌数没有变，奖励池位置变了。模型只看连续普通战奖励：当前蓝杂技在 20 / 25 组奖励里一次都没出现的概率是 53.1% / 45.3%；只把稀有度改回白卡，则降到 16.4% / 10.5%。**能确认的是取得难度，不是奇巧牌本身被削。**

**阅读路径：**[一代的基线](./full.md#section-2-1) → [杂技升蓝](./full.md#section-3-1) → [组件单独上手时](./full.md#section-3-2) → [精简更贵](./full.md#section-3-4)

### 为什么「持续收益」在这两代里更划算？

当反复抽弃的组件不易按计划补齐、精简与有效加费各有成本、终局又要求同时覆盖多组约束时，先部署、随后继续获得收益的路线减少了每回合重新组织输出的需求。沙漏把这一点照得更清楚：自动施毒不增加出牌数，而反复打攻击与抽牌要继续承担计数与污染。

**阅读路径：**[女王：可替代的功能](./full.md#section-4-2) → [实验体：技能惩罚与阶段期限](./full.md#section-4-3) → [沙漏与双 BOSS](./full.md#section-4-4) → [毒防为什么更有吸引力](./full.md#section-6-2)

### 官方目标兑现了吗？

四条意图分开判：「让无限更难形成」的目标与干预已确认，整体达成程度未验证；供给干预已实施，强度与体验的净效果未验证；准备重做被撤回，但原始准备得以保留；确有补偿动作，补偿是否足够未知。**「只动供给，没动机制」不成立，但「改动没回滚，所以成功」同样不成立。**

**阅读路径：**[官方目标逐条对照](./full.md#section-6-1) → [开发者实际用过哪些办法](./full.md#section-7) → [仍待验证的问题](./full.md#section-8)
