# FTG 角色原型：D 系位移与连段选路

**个人项目 · 设计实验 · Godot 可运行原型**

能否用 BB Drive System 式的输入组织，简化 Seth 式连段中反复的位移指令，同时保留位置选择？这个 Demo 把部分位移攻击放进 D 系，实现了双换边搬运、抵墙短线和原版边保位。**位移输入得到集中，墙距仍决定连段如何继续。**

当前八样本路线已完成机器验证；这一版的操作宽容度与真人手感待试玩。公开版本固定为 `6998168`，功能报告日期为 2026-10-12。

## 这份作品展示什么

| 设计工作 | 具体成果 |
| --- | --- |
| 将体验目标转成招式职责 | D 系承担位移、换边与地空转换，命中和空间共同决定穿越结果 |
| 组织连段与位置收益 | 长线搬运、抵墙结束和原版边保位各有对应路线，八个样本有固定输入与回放记录 |
| 调整参数并检查代价 | 缩短 2C 前摇，让两轮 D 后的扫倒接回同一连段，同时核对整招攻防变化 |

## 一个值得继续调的问题

长线的关键 `jC` 连接仍有 1 帧窗口。**部分动作少了复杂指令，整条路线仍要求严格节拍。** 下一轮将围绕实际失败原因与墙距选路进行试玩，检查哪些执行要求值得保留、哪些需要放宽。
